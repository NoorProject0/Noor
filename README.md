# Nour | نور

نسخه 0.4 — PWA متن‌باز و آفلاین‌محور. (قبلاً «رها» / Raha)

## چیست
اپلیکیشن وب فارسی برای آمادگی پیش از اختلال اینترنت. پس از یک بار باز شدن با اینترنت، بدون اینترنت هم باز می‌شود.

## محتوا
- **ابزارهای اینترنت:** راهنمای نصب و اتصال Psiphon، Proton VPN، Tor Browser، Windscribe، Cloudflare WARP و Amnezia Free، و راه‌های دانلود وقتی سایت رسمی بسته است.
- **منابع و آموزش‌ها:** کمک‌های اولیه (احیا، خفگی، خونریزی، سوختگی، رگ‌به‌رگ‌شدن، غش، گرمازدگی)، امنیت دیجیتال، مدیریت ارتباطات و Briar.
- **نقشه‌های آفلاین:** راهنمای دانلود نقشه‌ی ایران با CoMaps یا Organic Maps. نقشه‌ی شهرها داخل خود برنامه نیست.
- **راهنمای آمادگی:** چک‌لیست قابل تیک‌زدن (فقط روی همین دستگاه ذخیره می‌شود).

## انتشار در GitHub Pages
1. محتویات این پوشه را در یک مخزن عمومی GitHub قرار دهید (Add file › Upload files).
2. Settings › Pages › Deploy from a branch › شاخه main و پوشه /(root).
3. آدرس Pages را باز کنید و یک بار آنلاین بمانید تا پوسته‌ی برنامه کش شود.

برای نصب PWA به HTTPS نیاز است. در iPhone از Share › Add to Home Screen استفاده کنید.

## به‌روزرسانی
فایل‌های جدید را با همان نام روی قبلی‌ها آپلود کنید. نسخه‌ی کش Service Worker (`nour-pwa-v2`) را در `service-worker.js` بالا ببرید تا گوشی‌های نصب‌شده نسخه‌ی جدید را بگیرند.

## فونت
فونت Vazirmatn از Google Fonts بارگذاری و برای استفاده‌ی آفلاین کش می‌شود. اگر Google Fonts در دسترس نباشد، فونت سیستم نمایش داده می‌شود.

## حریم خصوصی
اطلاعات شخصی جمع‌آوری یا ارسال نمی‌شود. فقط تیک‌های چک‌لیست در حافظه‌ی خود مرورگر ذخیره می‌شود.

## محدودیت‌ها
- ترتیب و کارکرد ابزارها در ایران از گزارش‌های وب گرفته شده و آزمایش نشده.
- لینک‌های خارجی بدون اینترنت کار نمی‌کنند.
- مراحل برای اندروید نوشته شده؛ روی iPhone ظاهر برنامه‌ها کمی فرق دارد.
