# Raha | رها

نسخه 0.3 — PWA متن‌باز و آفلاین‌محور.

## تغییرات نسبت به 0.2
- بخش «نقشه‌های آفلاین»: معرفی Organic Maps، CoMaps، Google Maps و برنامه‌های ایرانی با مراحل آماده‌سازی پیش از قطعی.
- نسخه‌ی کش Service Worker بالا رفت تا گوشی‌هایی که قبلاً نصب کرده‌اند نسخه‌ی جدید را بگیرند.

## تغییرات 0.2 نسبت به 0.1
- رفع خطای CSS: یک پرانتز بسته‌نشده در متغیر `--shadow` باعث می‌شد کل استایل‌شیت نادیده گرفته شود.
- بخش «ابزارهای اینترنت»: شش برنامه‌ی رایگان با رتبه‌بندی برای ایران، و راه‌های دانلود وقتی سایت رسمی بسته است (آینه‌ها، GetTor).
- ناوبری با آدرس (`#tools` و مانند آن)، تا دکمه‌ی بازگشت گوشی کار کند.
- حالت روشن و تاریک از تنظیم سیستم پیروی می‌کند؛ دکمه فقط در نشست جاری تغییرش می‌دهد.
- آیکون‌های SVG به‌جای نمادهای متنی، رنگ متن پررنگ‌تر و اندازه‌ی فونت حداقل ۱۲ پیکسل.
- آیکون PNG برای نصب روی اندروید و iPhone.

## انتشار در GitHub Pages
1. محتویات این پوشه را در یک مخزن عمومی GitHub قرار دهید.
2. Settings → Pages → Deploy from a branch → شاخه main و پوشه /(root).
3. آدرس Pages را باز کنید و یک بار آنلاین بمانید تا پوسته‌ی برنامه کش شود.

برای نصب PWA به HTTPS نیاز است. در iPhone از Share → Add to Home Screen استفاده کنید.

## حریم خصوصی
اطلاعات شخصی ذخیره یا ارسال نمی‌شود. Service Worker فقط فایل‌های خود برنامه را کش می‌کند.

## محدودیت‌ها
نقشه‌ی داخلی و دانشنامه‌ی آفلاین هنوز پیاده نشده‌اند. لینک‌های خارجی بدون اینترنت کار نمی‌کنند. رتبه‌بندی برنامه‌ها از گزارش‌های وب است و آزمایش نشده.
